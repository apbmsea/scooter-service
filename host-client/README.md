# Host Client

Основной хост-сервер для микрофронтенд архитектуры проекта Scooter Service.

## Описание

Host Client - это центральный сервер, который:
- Управляет маршрутизацией между микрофронтендами
- Обеспечивает авторизацию и контроль доступа
- Проксирует статические ресурсы микрофронтендов
- Рендерит HTML-шаблоны с подключением нужных MFE
- Управляет запросами к Gateway

## Технологии

- **TypeScript** - основной язык разработки
- **Express.js** - веб-сервер
- **HTTPS** - защищенное соединение с самоподписанными сертификатами
- **ESLint** - линтинг кода

## Установка и запуск

1. Установка зависимостей:
```bash
npm install
```

2. Настройка переменных окружения в `.env`:
```env
HOST_IP=10.4.3.84
HOST_URI=https://10.4.3.84:5000
SERVER_PORT=5000
GATEWAY_URL=https://10.4.3.81:8081
MFE_HEADER_PORT=3000
MFE_HOME_PORT=3001
MFE_AUTH_PORT=3002
MFE_USER_PORT=3003
MFE_ADMIN_PORT=3004
MFE_MONITORING_PORT=3005
```

3. Запуск в режиме разработки:
```bash
npm run dev
```

## Скрипты

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка TypeScript в JavaScript
- `npm run build:public` - компиляция клиентских TS файлов

## Архитектура

### Микрофронтенд менеджер

`MicrofrontendManager` управляет жизненным циклом микрофронтендов:
- Предзагрузка всех MFE при инициализации
- Динамическое подключение/отключение MFE по маршрутам
- Монтирование/размонтирование компонентов

### Система ролей

Поддерживаются роли:
- `unauthorized` - неавторизованный пользователь
- `user` - обычный пользователь
- `operator` - оператор
- `admin` - администратор

### Маршрутизация

Конфигурация маршрутов в `endpoints.config.ts` определяет:
- Доступные пути
- Разрешенные роли для каждого пути
- Микрофронтенды для загрузки
- Метаданные страниц

### SSL сертификаты

Автоматическая генерация самоподписанных сертификатов при первом запуске.

## API

### GET /api/page-config/:path
Получение конфигурации страницы для клиентского роутера.

### GET /api/microfrontends-config
Получение списка всех микрофронтендов.

### Proxy /:mfeName-mfe-assets/*
Проксирование статических ресурсов микрофронтендов.

## Разработка

### Добавление нового микрофронтенда

1. Добавить конфигурацию в `microfrontends.config.ts`
2. Добавить маршруты в `endpoints.config.ts`
3. Настроить переменные окружения для портов

### Добавление нового маршрута

1. Добавить конфигурацию в `endpoints.config.ts`
2. Указать разрешенные роли
3. Определить необходимые микрофронтенды

## Безопасность

- HTTPS соединение
- Проверка ролей на каждом маршруте
- CORS настройки
- Валидация токенов через Gateway
