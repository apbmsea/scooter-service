# Home MFE

Микрофронтенд домашней страницы для scooter-service.

## Описание

Главная страница приложения с плиточным интерфейсом, отображающая основные разделы сервиса.

## Функционал

- Адаптивная сетка плиток с информацией о сервисе
- Разделы: Тарифы, Бонусы, Зоны катания, FAQ
- Кнопка быстрого старта поездки
- Футер с навигацией

## Технологии

- React 19
- TypeScript
- SCSS
- Vite
- scooter-shared

## Установка

```bash
npm install
```
Локальная разработка mfe без инициализации проекта
```bash
npm run dev
```
Инициализация mfe для prod и итнеграции в проекта
```bash
npm run build
```
```bash
npx serve dist -p 3001 -C
```

## Структура

```
src/
├── app/
│   ├── assets/images/  # Изображения
│   ├── App.tsx         # Точка входа
│   └── main.tsx        # Точка инициализации приложения
└── pages/
    └── HomePage/
        ├── ui/
        │   ├── HomePage.tsx   # Компонент страницы
        │   └── HomePage.scss  # Стили
        └── index.ts
```

## Плитки

### Размеры
- `tile--lg`: 2x2 (на мобильных 1x1)
- `tile--md`: 1x1
- `tile--sm`: 1x1

### Темы
- `tile--white`: белый фон
- `tile--blue`: синий фон (#0077ff)
